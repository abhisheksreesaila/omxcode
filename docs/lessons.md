# Lessons

One line per rule that prevents a mistake that happened.

- Mojo frees a value right after its last use, and `Int(x.unsafe_ptr())` doesn't count as a use: keep buffers you hand to C alive past the C call (e.g. `_ = len(buf)` afterwards).
- Mojo rejects one C function declared with two signatures in a module (even `0` vs a string pointer): pass the same types everywhere, or look the function up with dlsym and cast (`ccall`, `msg`).
- Callbacks from GTK/AppKit can re-enter while a `mut self` method runs; never rely on a Mojo field to block them (keep the flag in the toolkit, or defer work to the next main-loop turn).
- htmx inherits hx-* attributes from ancestors (bit us twice: hx-vals, hx-target). `disableInheritance` (on in mojoui/hosts/web.py) stops most of it, but **hx-vals is still merged from ancestors**: every element must set every hx-vals key it relies on itself.
- A GTK drag gesture reports coordinates relative to the widget it's attached to: never attach it to the widget it moves (jitter); attach it to the container and hit-test.
- Under htmx with `swap: 'none'`, a `<script>` in the response is not executed: send a hidden element with data attributes and let the page's adapter apply it.
- Never sort 20M rows with a comparison sort keyed on a few distinct values (quadratic): gather the column and radix-sort it.
- On GTK a `Spacer()` inside a card header expands vertically too and starves the card's canvas: push header items apart with `.justify(BETWEEN)`.
- GTK test windows go on the headless display (`scripts/headless.py`), never the desktop; a window covered by another gets no frame-clock ticks, so fps checks on a real screen are unreliable.
- Never run benchmarks or rebuild one platform of an example while a regression check runs: GPU timings pick up the extra load and the "built from the same app.mojo" check fails when only Linux was rebuilt.
- Look at every screenshot a check takes: a missing glyph (▲/▼ drew as a box) and a page wider than a 1280-pt window both passed the state checks.

- `Int(X)` of a comptime float constant (`comptime ROW_H = 26.0`) fails to compile ("the SIMD type must be floating point"): keep an Int constant beside it, or convert through `Float64(X)`.
- Never edit source while a full check runs: it rebuilds from the working tree, so half-written code turns into false failures (goal 11's first full run).
- Archived checkers (docs/goals/NN-check.py) ignore milestone arguments, rebuild everything and don't start the headless display: call their functions from a script that runs headless.ensure() first, never the file directly.
- To stop a check use scripts/stop-check (by argv and directory); never pkill -f / pgrep -f on its command line: it matched and killed my own shell twice.
- On the Android emulator, heavy load can leave a "System UI isn't responding" dialog over the app ("no Button #0"): scripts/android_drive.py closes system dialogs before each launch.
- 2026-10-18 · (encoded 2026-10-21) A stopped `scripts/check` left its Xvfb display running and orphaned displays broke the next runs' headless Chromium; cleaning them by hand with `pgrep -f` killed my own shell again. `scripts/stop-check` now stops this checkout's displays too (by process name and directory).
- GTK and web test runs print only the last screen's labels: check a state that lasts (a button's title), not a message a later step replaces.
- 2026-10-18 · Checks proved state, never looks: the GTK Format menu's submenu rows had button chrome and a bigger font for weeks. Compare every changed screen against its design image side by side (open:/pause: test steps + a display grab catch popovers).
- 2026-10-19 · A new message constant fell inside another's range (COPY = 41 inside RECENT 40–49): Copy silently did nothing. Before picking a message number, grep the app's `m >= X and m < X + n` ranges.
- 2026-10-19 · A view whose number of children depends on the selection (status items, inspector controls) rebuilds the whole screen on every move, restarting canvases and animations: keep fixed slots (StatusBar's 8).
- 2026-10-19 · A test-only probe must fail when the thing never stops: GLIDE first passed on a 2 s timeout; it now reports "settled".
- 2026-10-19 · (encoded) The "a changing child count rebuilds the whole screen" lesson came back a second time (a drag died when the inspector changed): it is now structure, not a rule: the diff keeps every widget it can (tests/test_diff_keep.mojo, goal 25 M1 counts full rebuilds).
- 2026-10-19 · Test steps call the host's handlers directly, so they never saw a rebuild kill a GTK drag in progress. Anything gesture-shaped is proven with real input too (scripts/live.py: XTest on the headless display, `report` prints the state).
- 2026-10-19 · Every check ran at 1440×900, the size the layout's constants were made for, and passed while the owner's 1742×876 window lost its status bar. Layout checks run at several window sizes (goal 25 M2: three).
- 2026-10-19 · Count bytes with code, not by hand: " · " is 4 bytes in UTF-8 and a hard-coded 5 ate the first digit of "5,000 of 5,000 rows".
- 2026-10-19 · A new view passed its own check ("the logo is there") while it broke the layout around it (a 100 px SVG stretched the web's menu bar under the toolbar; only goal 24's regression run caught it). A check for something added to a bar also checks it fits the bar.
- 2026-10-19 · Moving a style sheet "verbatim" moves its unscoped rules too: before splitting CSS by owner, list every rule that isn't under the owner's class (they were global), and prove the move with before/after pixels of every screen, run twice for the noise (goal 27 M3 caught the toolbar).
- 2026-10-19 · A handler for a message range (CHOICE = 1900 + k, "k < 100") silently ate a later message numbered inside it (ASK = 1990): give every range its documented bound in the constant's comment and number new messages past every range's end.
- 2026-10-19 · Typing in a field must not change anything else on screen: clearing a mark on each keystroke rebuilt the widgets under the field and Return (sent during the rebuild) was dropped. A field's on_change touches only its own text.
- 2026-10-19 · Replacing a function by slicing from its def to the next known def also deletes whatever was added between them (ask_here vanished with set_chart's rewrite): replace exact text, or slice to the next def, and diff the removed defs (git diff | grep '^-    def') before building.
- 2026-10-19 · The owner's launcher (scripts/omxplorer.sh) rebuilds into the same build/ the checks run from: launching the app mid-run crashed M6 and M7 with a missing binary. While a run is going, tell the owner the no-rebuild command (pixi run build/omxplorer/linux/omxplorer); next goal, give checks their own build folder.
- 2026-10-20 · A full `scripts/check` builds from the worktree's live files: never edit that worktree while it runs; make fixes in a second worktree and merge after (goal 29: a half-edited file failed every build).
- 2026-10-20 · On a loaded emulator, taps sent back to back went missing ("click 2" after 3 taps, twice in goal 29's full runs): scripts/android_drive.py waits for each Button tap to change the screen (up to 2 s) before the next step.
- 2026-10-21 · New message numbers must be checked against the ranges update() claims, not against a list of the constants: the island's 85–87 sat inside STYLE_ALIGN's 84–87, so pressing the island aligned the selected cells. Encoded: scripts/msgs.py (goal 30 M3 runs it over every example).
- 2026-10-21 · `git checkout <file>` to drop one experiment also drops every other uncommitted edit in that file: commit before experimenting, or undo the experiment by hand.
- 2026-10-21 · Moving work onto frames (polled jobs) needs every host that drives the app to send frames, the agent host included: goal 30 checked GTK and the web, and the agent's opens never landed. A new mechanism names each host it must reach in its check.
- 2026-10-21 · A check runner that catches a crash prints its traceback (scripts/check now does): a bare IndexError from ten goals deep cost a 10-minute rerun.
- 2026-10-21 · Dropping an MX frame `Job` detaches its thread, it doesn't stop it: every cancelled handle that may still read shared data (a table, its GPU copy) is kept and waited for before that data goes (reviewer round 2, D-284).
- A wait loop with a deadline must never block inside the loop (a blocking main-loop turn, a join, a read): the deadline is only read between turns. Guarded by scripts/check M5 for the GTK host (D-286).
- 2026-10-22 · Every claim on the site (numbers, "runs", "every", "on the GPU", motion values) cites a file in the repo before it ships; the owner caught "the model is live" and an audit found 19 overstatements (medians on the CPU, the web is a server round trip, Mac never run, old spring values). Check claims against EXPERIMENTS.md, docs/components.md and the code, not the old spec.
- 2026-10-23 · Never rebuild the screen (or set the menu bar) from inside a window notification: windowDidResize: can arrive in the middle of AppKit's layout pass, and macOS 26 aborts when setMainMenu: re-lays its menu bar there (omxplorer crashed on opening the Report). Host notifications only queue work for the next run-loop turn (common modes, so it stays live during a drag).
- Mac layout: no default size, scroll content or label may hold a constraint above 500 against the window (a window grows to satisfy anything above NSLayoutPriorityWindowSizeStayPut); the app sizes views to its window, so a few extra points (a legacy scroll bar) grew the window without end. Priorities: prefer 480, wrapping label 490, scroll content width 495, button compression 760.
- A host must patch a view's new size in place (SET_SIZE), not rebuild the window: the island's 60 Hz morph rebuilt omxplorer's window every frame and threw every drawn chart away.
- Test the Mac on GitHub's Macs before asking the owner: build, `scripts/mac-ci`, read the pictures; the owner gives the feel at the end.
- An audit that finds nothing proves only what it read: list the folders it scanned in its output, and check one known hit before trusting a clean result (gpu_audit read MX frame's mojo/ and missed kernels_aot/, D-305).
- When a setter seems to do nothing on a platform, dump the value it should have changed before trying another fix: AppKit kept the scroll bar style the system chose, and two "set it later" attempts were spent before the dump showed `bars 0`.
- Never hand C a `Pointer(to=x)` as an out-parameter: the compiler may keep x's old value (a refused connect read as success). Give C a `List` buffer and read it back after the call, keeping the list alive (`_ = len(buf)`).
- A GLib timeout that fires every few ms at the default priority starves GTK's redraw (priority 120): poll background work at G_PRIORITY_DEFAULT_IDLE.
- Showcase apps compose only generic mojoui components and theme roles; never app-specific CSS, pixel nudges or app-named host code (owner, 2026-10-25). Enforced by the console lint in m4().
