# Personal Note on omxcode: the gap audit

2026-10-31. Could omxcode build Personal Note (`~/Projects/personalnotev2`) the exact same way, with the same or better feel? This audit checks every feature against the framework (`mojoui/`). It doesn't build anything. The data is in [personalnote.json](personalnote.json) for the scoreboard. An older, shorter audit is `personalnotev2/docs/research/omxcode-gap-audit.md`; the probes it asked for (Sketch, Jot, Dictate, Keeper, Recall) have since been built, so this one replaces it.

## Verdict

**Partly, not the same way today.** Not the same way today: storage, search, voice, background work and the shell are there and often faster, but the editing heart (objects on a canvas, Markdown on a canvas, mind maps, ink tied to text) is missing.

- 53 features: **18 have (34%)**, **22 partial (42%)**, **13 missing (25%)**.
- 19 of the gaps block a faithful rebuild. Most of them sit in the editors: canvas objects, text on a canvas, mind maps, and ink tied to text. These are what a user of Personal Note touches every minute.
- Where omxcode is already ahead (measured): keyword search, search by meaning, dictation, pan and zoom, saving on close, running with the window closed, and agent access without a hand-written CLI. Details under **Wins**.
- Hosts: nearly everything that works runs on Linux (GTK) and the web, checked by tests. The Mac builds but has never run. The phones are early. Personal Note's own target is the desktop (Linux and Mac), so the Mac run is the next platform risk after the gaps.

Checked in this audit by running them: `tests/test_sqlite.mojo` (FTS5 ok), `tests/test_ink.mojo` (ok) and `tests/test_tray.mojo` (all ok, including notify). The tray test only passes on a private D-Bus, which is how goal 45's checker runs it. On the owner's live desktop it fails, because a real panel is present. Search by meaning (goal 44, Recall) passes its checker on branch `goal-44-recall`, but that branch **isn't merged into main**.

## Ordered gap list (the shortest path)

Good showcase videos come first. Then come the gaps that block the rebuild without making a good video. Each item is a generic `mojoui` component with its own test, never an app hack.

1. **merge goal 44 + CommandPalette composite + the cut-off rule** (S, this week). Gap: Search by meaning not on main; no command palette. Unblocks: Search by meaning; Omnibar (Ctrl+K).
2. **mojoui.history** (S, this week). Gap: No generic undo. Unblocks: Undo and redo with edits merged.
3. **mojoui.objectlayer (with connectors)** (L, Dec 2026). Gap: No objects on a canvas (select, move, resize, rotate, z-order, connectors). Unblocks: Objects on the canvas; Arrows between objects that re-route when an end moves.
4. **Markdown into a Painter + a multi-line in-place editor** (M, Nov 2026). Gap: No Markdown text drawn and edited on a canvas. Unblocks: Markdown text drawn on the canvas (headings, lists, task boxes, code, quotes); Edit canvas text in place, Markdown symbols hidden except on the caret's line.
5. **mojoui.mindmap (tree layout, ribbon branches, node keys)** (L, Dec 2026). Gap: No mind map. Unblocks: Mind map editor; Jam.
6. **text anchors + an ink layer over a text view** (L, Dec 2026). Gap: No ink anchored to text. Unblocks: Ink over the page; Ink marks anchored to words that follow the text when it reflows.
7. **notification actions, App.fullscreen, clipboard pictures, window-wide shortcuts, a short sound** (S, this week). Gap: Small platform hooks. Unblocks: Due dates and reminders; Focus mode; Insert pictures (picker, drop, paste), shrink to 1,400 px off the UI thread, stored by SHA-256.
8. **HTTPS via the system's libcurl at run time + mojoui.process** (M, Nov 2026). Gap: No HTTPS and no way to start a program. Unblocks: Download models in the app with SHA-256 checks and resume; AI settings; X bookmarks.
9. **mojoui.crypto (libcrypto at run time) + SecretStore (libsecret / Keychain)** (M, Nov 2026). Gap: No encryption and no keychain. Unblocks: Secure notes; Keys and API tokens in the keychain.
10. **mojoui.zip** (S, Nov 2026). Gap: No zip. Unblocks: Markdown + assets ZIP; Obsidian vault export and import.

Later, not blocking on the desktop: printing through the system dialog, Mac platform calls (Touch ID, hiding from screen capture, the microphone), touch on real phones, installers and notarization. The Mac items need the owner's Mac. Phone touch needs real hardware (2027).

Honest ETAs: *this week* is S work that reuses pieces already proven. *Nov 2026* covers loading a system library at run time, the way `mojoui.sqlite` already loads libsqlite3. *Dec 2026* is the three L editors, about one goal each. *2027* is anything that needs hardware the checks can't reach.

## Wins (where omxcode would beat the original)

- **Keyword search and opening a big notebook.** Jot vs SQLite-wasm on OPFS at 1M notes: search p95 64.6 vs 165.8 ms (2.6×), cold open 65.8 vs 435.3 ms (6.6×), goal 42. Personal Note itself uses server-side SQLite, so against it: unproven.
- **Search by meaning in one process on the GPU.** Recall: top-10 over 1M in 2.2 ms, 7.7 ms p95 as you type (goal 44, unmerged branch). Personal Note scores in a Python loop; at 1M its per-row loop takes seconds per query (D-1519, 3 queries). The side C race against its llama.cpp helper has no recorded result yet: unproven.
- **Dictation latency.** whisper-large-v3-turbo in process: 140 ms vs transformers.js 912 ms, same WER (goal 43). Against Personal Note's nemo-speech server over a WebSocket: unmeasured.
- **Pan and zoom with lots of ink.** Sketch: pan, zoom and draw p95 ≤ 3.5 ms with 101k points (goal 40). The older audit quotes Personal Note's zoom p95 as 97 ms, on another machine: not a fair race yet.
- **Saving on close and running with the window closed.** App.closing() runs in the same process (no 64 KiB keepalive request, no server lingering after close); background mode, tray and notifications checked (goal 45). Personal Note stops voice when the window closes.
- **Agent access without writing a CLI.** Every omxcode app is MCP tools through the agent host (docs/agent.md); Personal Note hand-wrote a 470-line CLI and 60 routes.
- **One program instead of three.** Personal Note is Python server + JS page + llama.cpp + nemo-speech processes over loopback; omxcode runs UI, search, embeddings and speech in one process (docs/probes.md). Fewer moving parts is measured in lines only in goal 44 M5, not yet recorded.

## What Personal Note doesn't need

Personal Note has no tray, no global hotkey, no file watching, no service worker, no wikilinks or backlinks, and no cloud sync apart from the X import. So omxcode's Keeper pieces (tray, watcher, background mode) are wins on offer, not requirements. Personal Note's three helper processes (the Python server, llama.cpp and nemo-speech over loopback) become one process in omxcode. Its 60 HTTP routes become plain function calls, because the UI and the data live in the same program.
