One file

Button to GPU kernel. Nothing to glue.

struct Main(App):
    def view(self) -> View:
        return VStack(Image(self.pixels, W, H),
            Button("Run on GPU", on_tap=RUN))
    def update(mut self, event: Event):
        if event.message == RUN:
            var o = self.gpu.render[mandelbrot](
                W, H, p)

Little to learn

Every app is two functions.

view() draws. update() reacts. Less for an agent to get wrong.

viewdef view(self) -> View:
    return Button("Tapped " + String(self.n),
                  on_tap=TAP)
updatedef update(mut self, e: Event):
    if e.message == TAP:
        self.n += 1
tap→update()→view()
