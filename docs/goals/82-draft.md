## 3. Order and milestones

Small first, as asked; the Mac's file picker/save dialog come with M2/M4 because import and print need them. Each M: a check in
`docs/goals/82-check.py` that runs the real app (GTK on the hidden screen; the Mac over mac-ssh, the screen unlocked where a window must be
seen), plus a mojoui test for every new component.

- **M0 Typing stays smooth (standing, every milestone):** the typing rows of goal 79's race (600/stress typing frames, warmed and not; the 20,000-character paragraph; key to paint; M5's input method) re-run on Linux and the Mac at the end of each milestone: no row worse than its goal-79 value by more than 3 %; and, once Linux is free, fix the two close Linux rows (600 typing max 18.7 against the web's 16.8; key to paint 16.8 / 18.8–21.0 against 16.0) with a typing trace, generically in mojoui. Check: `82-check.py M0` runs the typing steps and compares with `docs/goals/79/race*.md`.
- **M1 Focus mode:** Ctrl+. / Cmd+. on a canvas text, a page and a map: only the words, the web's geometry (top 96, side 24, centred), word count; the same key restores tool, view, selection and caret exactly; real full screen optional. Check: before/after screen dumps and state equal after leaving; pictures against the web's at the same note (M2-style compare).
- **M2 Pictures:** drop, paste (from the system clipboard: a screenshot) and pick an image onto a canvas and into a page; stored as `media/<sha256>.<ext>` by the web's rules (1400 px, alpha → PNG, opaque → JPEG 0.85, GIF frozen, 100 MP and 20 MB refused, no SVG); placed at most 520 px, offset 28 for several; the web app opens the same note and shows the same picture at the same place. Components: clipboard images, media store, JPEG encode, Mac file picker. Check: the file's sha256 and size equal what the web's rules give for three test images; both apps' screenshots of the note match (SSIM ≥ 0.98 on the picture's box).
- **M3 Import:** backup JSON (round trip with the web's), Obsidian vault folder and zip (both ways, the web's `pn` extensions), JSON Canvas into a canvas; never changes what exists. Components: zip, jsoncanvas, folder picker. Check: import the web's export and the web imports pnote's: the notes' content equal (the web's API).
- **M4 Print and export:** the system print dialog (GtkPrintOperation; NSPrintOperation) with the note's pages as white paper; Picture (PNG of the note) and vector PDF; a share action (portal / NSSharingServicePicker). Components: print dialog, PDF writer, share, Mac save dialog. Check: the PDF's page count and size match the note's page grid, its text extractable (pdftotext finds the note's words), the PNG equal to the web's Picture export within SSIM 0.98; the dialog opened (its window seen) on both.
- **M5 Voice:** hold to talk (key and pointer), words streaming into the note at the caret, nothing but text stored; engine: mojoui.speech in process on Linux (GPU), Apple on-device speech on the Mac (no download), whisper on the Mac's GPU as the fallback; the Mac's microphone through AVAudioEngine. Check: a recorded WAV played as the microphone (a test source) transcribes to the expected words (word error ≤ 10 %) on both; first word on the screen within 1 s of speaking.
- **M6 AI:** Settings → AI (claude-code, OpenAI-compatible, Azure, and a local endpoint: max serve / omxconsole), key in the keychain; Jam on a map (add, react, ghost; never remove/rename; validated whole); agents through MCP and the existing CLI with Show / Undo of an agent's edit. Components: secret store, HTTPS on the Mac. Check: a recorded brain reply (no network in the check) produces exactly the web's edits on the same map; a key saved is never in a file, log or dump.
- **M7 Sync (as the web means it) + the deletion fix:** other apps' and agents' writes shown at once by file-system events (FolderWatcher on the notes file) instead of the feed's poll; the agent presence chip; the known deletion write-back fixed on our side and reported for the web. Check: goal 79's bothopen run with deletions: 0 lost, 0 come back, change shown in ≤ 300 ms (from 2 s today).
- **M8 Packages and the matrix:** both downloads rebuilt, installed and opened from their real files; components.md regenerated, every new part ✅ on Linux and the Mac.

## 4. Risks and owner-only steps

- **The Mac's microphone permission** (M5): the first run asks; **the owner clicks Allow** once (System Settings → Privacy & Security → Microphone, for pnote). Apple's on-device speech may ask for Speech Recognition permission too: **the owner allows it**.
- **AI keys** (M6): to try a cloud provider, **the owner pastes a key** in pnote's Settings → AI (or signs in to Claude Code, which pnote then uses as the web does). The checks use recorded replies and need no key.
- **Model downloads** (M5, M6): whisper weights (~1.6 GB) and any local LLM: downloaded by pnote into its data folder on the first use, after the owner says yes in the app; nothing is bundled. On the 3 TB data drive on Linux if the owner prefers (`/mnt/data`).
- **Sync beyond one machine** (device to device, a server, accounts) is **not in the web app and ruled out by its brief**; building it is a product decision for the owner (what server, who hosts it). This draft only does the web's kind of sync.
- **Print** needs a printer only to be seen working by hand; the checks print to PDF.
- Risks: vector PDF and the print dialog are new host code on two platforms (the largest unknown); voice on the Mac depends on Apple's APIs being reachable from our AppKit host (ObjC calls as today); the web's deletion bug is the web's to fix (we only avoid writing it back).
