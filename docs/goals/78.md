# GOAL 78: a free canvas: room to breathe, live resizing, keys, and video you can see

**End goal (owner, 2026-11-18, after recording with the ribbon):** "I still feel constricted… in Excel I can expand… go all the
way even if I have blank space… I want to see all my columns, I don't want to see three columns hidden and tiled"; "the handle
is only in one edge"; "I should be able to resize smoothly as opposed to just guessing what the size would be after I drag and
leave because it snaps"; "like Hyprland where you can move with one keystroke"; "I have no clue which column is video… it has
to have some sort of an indicator, a colour, a hyperlink… click on it and then I get the player… audio would be special".

## Assumptions (instead of asking)
- Overlap is allowed on a free canvas (as in Figma or a whiteboard); Tidy is how you get a clean grid back.
- Snap is soft (guides within 8 pt, Alt while dragging turns it off), never a jump after release.
- Zoom changes only the canvas's scale; the cards' own text stays crisp (drawn at the zoomed size, not a bitmap).
- Super and Alt both work; Super is what the owner asked for, Alt is what works under Hyprland without rebinding.
