How the sentence works

Words are buttons. Buttons are tools.

# mojoui/sentence.mojo
Sentence([Word("Sum", ASK_COMBINE, "word-combine"), Word(" of "),
          Word("amount", ASK_VALUE, "word-value")], width=46)

if w.msg != NO_MSG:
    line.append(Button(w.text, w.msg, TOKEN_LIT if w.lit else TOKEN).tag(w.tag))
else:
    line.append(Text(w.text, style))

A tag names the button, and the agent host turns every tagged button into an MCP tool. The word you tap is the word an agent calls.

mojoui/sentence.mojo (trimmed) · docs/agent.md
In code, a sentence is a list of words. Words with choices become buttons with a tag; plain words are text. Because the agent host turns every tagged button into a tool, word-combine is something you tap and something an agent can call.

Honestly

Where we're behind.

3D scenes

No 3D view yet: the robot is seen through video and telemetry lanes, not a scene.

MCAP · ROS bags

Not read yet. DROID comes in as a LeRobot dataset (mojoui/lerobot.py).

Teams

One person, one machine. Shared workspaces are a direction, not built.

More cameras

One of DROID's three cameras, video for 3,546 episodes. Wrist and right views are next.

Replay tools like Foxglove and Rerun are great for replaying a recording, and between them offer 3D, ROS bags and teams. We start one level up, from a question across the fleet, and want to sit alongside them.

docs/goals/47-report.md "Growing it", "Not done" · docs/launch/kit/modular-forum/replies.md · repo has no MCAP/ROS reader (grep, 2026-11-01)
Here's where we're behind. Tools like Foxglove and Rerun are great for replaying a recording, and between them they offer 3D, ROS bags and teams. omxplorer has none of those yet, no MCAP reader either, and it shows one camera of DROID's three. We start one level up, from a question across the whole fleet, and I'd like it to sit alongside those tools, not replace them. All four of these are on the list of what's next.
