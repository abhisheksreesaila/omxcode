# omxplorer

omxplorer is a workbench for robot learning data. It opens robot episodes, video, telemetry, ROS 2 bags, tables and
documents side by side, and does the heavy work on the GPU. It is agent native: every button on its screen is also a
tool an agent can call over MCP. It is written in Mojo on omxcode, the app framework in this repo. It runs on Linux
today. Mac builds are built and checked on CI Macs. A web copy is in progress.
